# Overview
This repository contains software tools for the Nand2Tetris computer system, implementing the translation pipeline from high-level code down to machine code.

The process follows these stages:

High-level language → VM code → Assembly → Binary

- A compiler translates high-level code into VM instructions
- The VM Translator converts VM instructions into assembly
- The Assembler converts assembly into binary machine code executable on the 16-bit Hack computer

---

# VM Translator
The VM Translator is responsible for converting virtual machine (VM) code into Hack assembly.

- The VM language serves as an intermediate representation, similar in concept to Java bytecode
- Input: VM code (typically generated by a compiler)
- Output: Hack assembly code

### Current Support
- Arithmetic and logical commands
- Memory access commands (push/pop)

### In Progress
- Program flow commands (label, goto, if-goto)
- Function calling commands (call, function, return)

---

# Assembler
The Assembler translates Hack assembly language into binary machine code.

- Input: Hack assembly code
- Output: 16-bit binary instructions executable on the Hack computer

### Features
- Symbol resolution (labels and variables)
- A-instruction and C-instruction translation
