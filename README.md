# Overview
- This repository contains software tools for translating high level code into machine code by first translating the code into an intermediate form that is then translated into assembly by the VM Translator and then into binary by the Assembler

# VM Translator
- Similar to a language like Java, the high level language used to write programs for this computer is first compiled into an intermediate form that is then further compiled into machine code in later steps
- The VM Translator is specifically responsible for translating VM code (generated by the compiler) into assembly

# Assembler
- Translates assembly code (generated by the VM Translator) into binary which is capable of running on the 16-bit computer
